# রসায়ন কারিগর (Rosayon Karigor) — Web Application

> **"বোঝো। প্রয়োগ করো। পারদর্শী হও।"**  
> *More than Memorization. A Deeper Understanding.*

A modern, high-performance web platform for **রসায়ন কারিগর (Rosayon Karigor)**, designed to transform how students in Bangladesh learn chemistry for SSC, HSC, and University Admissions (BUET, Medical, and Varsity 'A' unit).

---

## 🔬 Key Features

1. **Brand Identity & Design System**:
   - Custom palette: Deep Blue (`#09284C`), Ocean Blue (`#164B73`), Warm Soft Orange (`#F4A261`), and Warm Off-White (`#F7F5EF`).
   - Clean bilingual typography using Google Fonts (**Hind Siliguri** for crisp Bengali text, **Plus Jakarta Sans** and **Fraunces** for English).
   - Custom SVG Benzene & molecular node logo.

2. **Interactive 3D Canvas Molecular Simulation**:
   - Lightweight, hardware-accelerated 3D rotating molecular physics engine.
   - Switch between **Benzene ($C_6H_6$)**, **Water ($H_2O$)**, and **Methane ($CH_4$)**.
   - Interactive cursor-tracking rotation and electron cloud orbitals.

3. **The Karigor Method™ (কারিগর মেথড)**:
   - 5-step intuitive learning framework: `01 Understand` ➔ `02 Visualize` ➔ `03 Connect` ➔ `04 Practice` ➔ `05 Master`.
   - Before vs. After Karigor side-by-side transformation breakdown.

4. **Interactive Classroom Demo Experience**:
   - Video classroom mockup with simulated player controls (Play/Pause, scrub bar, volume, full screen).
   - Interactive lecture chapter selector (Chemical bonding, orbital overlap, and sigma/pi bonds).

5. **Free Chemistry Resource Library (উন্মুক্ত লাইব্রেরি)**:
   - Filter resources by curriculum: `All`, `SSC`, `HSC`, `Admission`, `Physical`, `Organic`, `Inorganic`.
   - Downloadable PDF concept notes, reaction mechanism roadmaps, and problem sets with instant preview modal.

6. **Meet the Karigor (শিক্ষক পরিচিতি)**:
   - Teacher story, teaching philosophy, and personal digital signature.
   - Interactive tabbed profile with teaching experience, academic background, and core specializations.

7. **Batch Reservation & Lead Enrollment Form**:
   - Student & Guardian segmented toggle.
   - Form validation with Bangladesh phone format verification.
   - Celebratory confetti on reservation and instant direct WhatsApp chat link.

8. **Frequently Asked Questions (FAQ)**:
   - Accessible accordion answering queries about online/offline batches, class recordings, exams, and doubt-solving.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Linter**: [Oxlint](https://oxc.rs/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
The optimized static files will be generated in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, Netlify, or Firebase Hosting.

### 4. Preview Production Build
```bash
npm run preview
```
